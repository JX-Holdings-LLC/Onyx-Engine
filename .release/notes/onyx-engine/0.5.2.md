# Onyx Engine 0.5.2

## Changes

Adds a plan for making Onyx Engine an independent tool that works best with JX Runtime (`reports/independent-tool-plan.md`): a Node-free build, repositioning, a stability policy, a supervisor guide, readiness and port selection, operator features, one-command distribution, a contributor loop and published evidence. Documentation only; the binary is unchanged from 0.5.1.
