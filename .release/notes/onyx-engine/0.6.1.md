# Onyx Engine 0.6.1

## Changes

Documentation only; the binary is unchanged from 0.6.0. The docs' statements about JX Runtime are corrected from a cross-repository audit (`firstHealthLoadingMs` shipped in JX Runtime 1.5.3, the `onyxengine` adapter always passes `--jinja`, JX Runtime proxies `/v1/systemone`, and its downloader learns `linux-arm64` after 1.5.8); the stability page, service endpoints and supervising guide now agree that a refused connection before the first `503` means "not yet" while the process is alive; 0.6.0 is filed under its own changelog heading; and the four moved-page stubs are removed. Nothing on the stability page changes behaviour.
