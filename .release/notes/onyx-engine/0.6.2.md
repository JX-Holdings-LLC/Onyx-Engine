# Onyx Engine 0.6.2

## Changes

Release pipeline only; the binary is unchanged from 0.6.1. The vendor source-package publish steps (`@jxburros/llama-cpp-source`, `@jxburros/ggml-source`) passed `npm publish` a bare `package-output/<name>.tgz`, which npm 11 reads as a GitHub `owner/repo` shorthand and tries to clone over SSH — the failure that stopped AI Nugget 0.7.1 and 0.7.2 from publishing. Neither vendor package has reached npm yet; the next vendor release would have hit it. Both steps now pass `./package-output/<name>.tgz`.
