# Onyx Engine 0.4.2

## Changes

- Adds a QA profile (`.ai/qa.yaml`, `.ai/qa.md`) for the nightly QA runner: install and verify the pinned llama.cpp source, run the smoke suite, build in Release, and serve a chat completion from the tiny test model. The checks run through `scripts/tools/qa-check.js` on Windows as well as Linux and macOS, and report a missing toolchain as a skip with its reason.
- `npm run build` builds Release with Visual Studio generators, which previously built Debug.

The engine's source is unchanged from 0.4.1.
