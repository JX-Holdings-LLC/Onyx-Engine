# Onyx Engine 0.8.2

## Changes

Build and CI only; the server behaves as in 0.8.1. A monthly `pin-bump` workflow and `scripts/bump-llama-pin.sh` propose llama.cpp pin moves as draft pull requests with the diff of every upstream header Onyx compiles against. The build forces ggml's RPC backend off and stops if it appears, and CI checks every build for it (`scripts/check-no-rpc.sh`). A new `sanitize` CMake preset and a CI job run the unit and smoke tests under AddressSanitizer and UndefinedBehaviorSanitizer.
