# Onyx Engine 0.5.0

## Changes

- Serves decision ("System One") models on `POST /v1/systemone`, with llama-server's request and response shapes, for every decision family llama-server supports. Images work for openjev, pplx-decider, lfm2-d1 and h2o-lightning with `--mmproj`. A decision model serves only this route, and `/props` reports its `decision_type`.
- Builds against llama.cpp b11820 (`d77256999`), up from b10711.
- Special tokens written in chat message content are no longer parsed as control tokens.
- CI and release workflows use current major versions of `actions/cache`, `actions/download-artifact`, `actions/upload-artifact` and `actions/setup-node`.
